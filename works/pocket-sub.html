PocketSub

日々増えていくサブスクリプションを一覧・カテゴリ別に管理できるSaaSアプリです。今月の月額換算コストを自動計算し、 Claude APIが利用状況から支出見直しの提案を行うことで、無駄なサブスクの見落としを防ぎます。

  • サブスク管理
  • AI支出見直し提案
  • SaaS UI
実際のサイトを見る ↗

概要

動画配信やクラウドストレージ、音楽配信など契約するサブスクリプションが増えるほど、総額の把握や使っていないサービスの 見直しは後回しになりがちです。PocketSubはサブスクを一覧・カテゴリ別に整理し、月額・年額が混在する契約でも 月額換算した合計コストを自動計算する設計により、現状の支出を一目で把握できるようにしています。 さらにClaude APIが登録内容から利用頻度の低いサブスクや契約プランの見直しポイントを提案し、支出の最適化を後押しします。

主な機能

サブスク一覧・カテゴリ別管理

動画配信・音楽配信・クラウドストレージなどカテゴリごとにサブスクを登録・分類し、一覧画面から契約状況を把握できる。

月額換算コストの自動計算

月払い・年払いが混在する契約を月額に換算し、カテゴリ別・全体の今月の合計支出をリアルタイムに集計して表示する。

検索・並び替え

サービス名やカテゴリでの絞り込み検索に加え、料金・次回更新日・登録日などの条件でサブスク一覧を並び替えられる。

Claude APIによる支出見直し提案

登録済みサブスクの料金・利用頻度メモをClaude APIに渡し、解約候補やプラン見直し候補を理由付きで提案として受け取れる。

次回更新日のリマインド表示

各サブスクの次回更新日を一覧上にハイライト表示し、更新が近いサービスに気づきやすくする。

レスポンシブなダッシュボードUI

Tailwind CSSでPC・スマホ双方に最適化したダッシュボードを構築し、合計コストや内訳をカードとグラフで可視化する。

工夫したポイント

バックエンドはGoの標準パッケージ（net/http）のみで構成し、フレームワークに頼らずルーティングやミドルウェアを 最小限の実装で組み立てることで、依存関係が少なく見通しの良い設計を意識しました。 月額換算のようなドメインロジックはハンドラから切り離して関数化し、テストしやすい形にしています。 Claude APIへの提案依頼はTool useでレスポンスの構造（対象サブスク・理由・提案内容）を固定し、 画面側でのパース処理をシンプルに保っています。

制作情報

  • Go (net/http)
  • PostgreSQL
  • Tailwind CSS
  • Claude API (claude-sonnet-5)
