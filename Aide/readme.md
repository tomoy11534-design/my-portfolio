# Aide — 面接サポートツール

就職・転職の面接を受ける本人のための、**準備 → 練習 → 本番 → 振り返り** を1つにまとめたツールです。
要件は [requirements.md](requirements.md) を参照してください。

## 機能
| 画面 | できること |
|------|------------|
| 準備 | 応募企業（職種・選考段階・面接日時・メモ）、逆質問リスト、想定質問、自分のエピソードの登録 |
| 練習 | AIが面接官役で1問ずつ質問 → 声またはテキストで回答 → 4観点のフィードバック。深掘り質問あり |
| 本番 | 面接官の声（PCの再生音）と自分の声（マイク）のリアルタイム文字起こし、いま聞かれている質問の要約、関連エピソードの提示、逆質問チェックリスト、メモ |
| 振り返り | 面接記録の一覧、AIによるまとめ（質問と回答の要約・良かった点・改善点・宿題）、Markdown 保存・コピー |
| 設定 | テーマ（OS連動／ライト／ダーク）、文字サイズ（標準／大／特大）、JSON エクスポート・インポート、保存容量 |

本番モードのAIは「質問の要約」と「登録済みエピソードの提示」のみで、回答文は生成しません。

## 必要なもの
- Node.js 22 以上
- Google Chrome（Web Speech API・画面共有の音声取得のため）
- Claude API キー（AI 機能）
- Deepgram API キー（ヘッドホン・イヤホン使用時に面接官の声を文字起こしする場合）

## セットアップ
```bash
npm install
cp .env.example .env   # ANTHROPIC_API_KEY と DEEPGRAM_API_KEY を設定する
npm run dev            # http://localhost:5173 を Chrome で開く
```

本番用にビルドして動かす場合：
```bash
npm run build
npm start
```

マイクと画面共有はセキュアな環境でしか使えないため、`localhost` で開いてください。

## 本番モードの音声の取り込み
| 取り込み方法 | 面接官の声 | 自分の声 | 話者の区別 |
|--------------|------------|----------|------------|
| ヘッドホン・イヤホン | 画面共有で取得した再生音 → 中継サーバー → Deepgram | マイク → Web Speech API | あり |
| スピーカー | マイク → Web Speech API（両者まとめて） | 同左 | なし |

ヘッドホン・イヤホン使用時は、開始すると画面共有の画面が開きます。
- ブラウザ版の面接（Meet・Zoom Web など）：「Chrome タブ」→ 面接のタブ →「タブの音声も共有する」をON
- アプリ版の面接（Zoom・Teams デスクトップ）：「画面全体」→「システム音声も共有する」をON

音声は保存せず、文字だけを記録します。共有した映像は使いません。

### キーボード操作（本番モード）
- `Alt` + `P`：一時停止・再開
- `Alt` + `M`：メモ欄へ移動
- `Alt` + `1`〜`9`：逆質問のチェック切り替え

## 構成
```
server/
  index.js        Express サーバー（開発時は Vite をミドルウェアとして組み込む）
  ai-routes.js    AI 機能の API（練習の質問・フィードバック、本番の解析、振り返りのまとめ）
  claude.js       Claude API の呼び出しと JSON 出力・エラー処理
  stt-relay.js    再生音の PCM を Deepgram へ中継する WebSocket（/ws/stt）
public/
  pcm-worklet.js  音声を 16kHz・16bit PCM に変換する AudioWorklet
src/
  app.vue         画面の切り替え・テーマ反映
  components/     各画面（準備・練習・本番・振り返り・設定）
  lib/            保存（localStorage）、バックアップ、音声取り込み、音声認識、Markdown 変換
```

## データ
- 保存先はブラウザの localStorage（キーは `aide:` で始まる）。端末・ブラウザをまたいだ移行は、設定画面の JSON エクスポート・インポートで行います。
- エクスポートファイルには面接の文字起こしが暗号化なしで入ります。API キーはサーバー側にあるため含まれません。

## 利用上の注意
メモの参照や文字起こしが認められている面接でお使いください。企業から録音・文字起こしについて指定がある場合はそれに従ってください。
